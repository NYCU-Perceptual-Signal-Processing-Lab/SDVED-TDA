# Singing Dry Voice Evaluation Database - Timbre Attribute Annotated (SDEVED-TDA)
We construct **SDVED-TDA** (Singing Dry Voice Evaluation Database with timbre descriptors annotated) by adding descriptor-level annotations to SDVED, which is part of the CCMusic database. The original SDVED provides overall timbre scores; SDVED-TDA supports sample-level timbre attribute prediction.

The initial descriptor set comprises **Bright, Thick, Pure, Soft, Magnetic, Slim, Thin, Rich, Dark, Sharp, Crisp, Shriveled, Round, Rough, Hoarse, Harmonious, Muddy, and Low**.

Audio sample order was randomized, and descriptor order was shuffled for each sample. Inter-rater reliability was assessed using **ICC(3,k)**; all descriptors except *Dark* achieved values above 0.7. Questionnaire responses about recommended descriptors and similar/opposite descriptor pairs informed selection of the five final dimensions.

Sample-level labels preserve timbre variation between performances by the same singer.
